## Conclusion sur la licence

Le moteur de référence est sous **GPL-3.0-or-later**. Notre travail est une **réimplémentation
indépendante** à partir de la compréhension de son architecture : aucun code, aucun identifiant
distinctif, aucun texte n'est recopié. Les idées d'architecture (graphe de tâches, empreintes,
scopes de dépendances…) ne sont pas protégeables par le droit d'auteur ; l'expression, si. Notre
code étant écrit à partir de zéro en Java (le moteur de référence est en Kotlin), sans reprise de
ses noms d'identifiants, il ne constitue pas une œuvre dérivée au sens de la GPL. Par prudence :

1. aucune portion de code du moteur de référence ne sera copiée, même adaptée ;
2. nos noms de classes, méthodes, packages et fichiers seront différents des siens ;
3. la licence de Forge est **Apache-2.0** (décision propriétaire du 2026-11-20, fichier
   `LICENSE`) ; choisir une licence copyleft ultérieure imposerait de réévaluer l'analyse
   ci-dessus pour chaque dépendance embarquée ;
4. si un doute subsistait sur un point précis, une réécriture documentation-uniquement
   serait préférée.

## Règles d'usage de ce registre

1. Toute affirmation sur le moteur de référence dans un autre document se cite `REF-xxx` ; le
   détail (chemin, lignes, SHA) ne vit qu'ici.
2. Une nouvelle lecture après un changement de SHA crée de **nouvelles** entrées (jamais de
   mutation silencieuse des plages de lignes).
3. Le statut `à vérifier` signale un constat non confirmé par lecture directe du code ; il n'est
   utilisé dans aucune décision de conception sans lever le doute.
